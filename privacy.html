Privacy Policy

Last updated: 2026-09-30

Yellowskill Channel Manager ("the tool") is an internal tool operated by Nana Company to manage our own YouTube channel "노란스킬". It is not offered to the public.

1. YouTube API Services

The tool uses YouTube API Services. By using the tool, users agree to be bound by the YouTube Terms of Service. Data accessed through YouTube API Services is also subject to the Google Privacy Policy.

2. Data we access

Only data about our own channel: video metadata, captions, channel analytics (views, watch time, subscribers, estimated revenue) and channel membership levels. We do not access other users' or channels' data.

3. How we use and store data

The data is used only to manage our channel and plan content. It is stored on our own computer and in our private spreadsheet. OAuth tokens are stored locally with owner-only file permissions. We never sell or share this data with third parties.

4. Retention and deletion

Stored API data is refreshed or deleted within the periods required by the YouTube API Services Developer Policies. Authorized access can be revoked at any time on the Google security settings page. To request deletion of stored data, email sasanana9094@gmail.com, and we will delete it within 7 days.
